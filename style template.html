ImpactLED Cloud+ Desktop Player
Windows Installation

Step-by-step installation guide for field technicians deploying the ImpactLED Cloud+ Desktop Player on a Windows 10 or Windows 11 machine.

Versionv1.0.5
PlatformWindows 10 / 11 (64-bit)
RevisedMay 2026
ClassificationInternal — Technician Use Only
1

Pre-Installation Requirements

Before beginning the installation, confirm that all of the following are in place. Do not proceed until every item is satisfied.

  • Windows 10 or Windows 11 (64-bit) — The player will not run on 32-bit Windows or Windows 7/8.
  • Active internet connection — The installer downloads the player executable directly from GitHub. No internet means no install.
  • Administrator access to the machine — The installer requires elevated privileges. Confirm with the site contact that you have local admin credentials before arriving.
  • Terminal ID — The device's unique identifier in Impact Cloud+. Obtain this from the Cloud+ portal before the visit (access.impactledsigns.com).
  • Terminal Secret — The authentication key paired to the Terminal ID. Obtain alongside the Terminal ID from the Cloud+ portal.
  • Display resolution — Know the target resolution (typically 1920 x 1080) before starting. The installer will prompt for this.
  • Display connected and powered on — The player launches immediately after install. The display should be connected via HDMI or DisplayPort before running the installer.
CMD vs. PowerShell Two versions of the install command exist — one for Command Prompt (CMD) and one for PowerShell. Use the correct command for whichever terminal you open. The CMD command uses %TEMP% syntax that does not work in PowerShell and will produce a "system cannot find the path specified" error if mismatched.
2

Opening an Administrator Command Prompt

The installer will immediately exit with an error if it is not running as Administrator. Follow these steps exactly.

  • 1

    Click the Start button or press the Windows key.

  • 2

    Type cmd into the search bar. Do not press Enter yet.

  • 3

    Right-click on "Command Prompt" in the search results.

  • 4

    Select "Run as administrator" from the context menu.

  • 5

    If a User Account Control (UAC) prompt appears asking "Do you want to allow this app to make changes to your device?", click Yes.

  • 6

    Confirm that the title bar of the Command Prompt window reads "Administrator: Command Prompt". If it does not say Administrator, close it and repeat from step 1.

3

Running the Installer

  • 1

    Copy and paste the command that matches your terminal type exactly as written. Do not retype it manually — a single missing character will cause it to fail.

    Command Prompt (CMD) — recommended:

    curl -fsSL https://raw.githubusercontent.com/Sacton86/Cloud-Desktop-Edition/main/full-install.bat -o %TEMP%\full-install.bat && %TEMP%\full-install.bat

    PowerShell (alternative):

    curl -fsSL https://raw.githubusercontent.com/Sacton86/Cloud-Desktop-Edition/main/full-install.bat -o "$env:TEMP\full-install.bat"; & "$env:TEMP\full-install.bat"
  • 2

    Press Enter. The installer will display a banner and begin downloading.

    You will see the following output confirming a successful start:

    ############################################################## ImpactLED Cloud+ Desktop Player Full Device Installer -- Impact LED Signs ##############################################################
  • 3

    Wait for the download to complete. You will see [OK] Download complete. when it finishes. This typically takes 10–30 seconds depending on connection speed.

Download Failure If you see [ERROR] Download failed, the machine cannot reach GitHub. Verify the internet connection is active, confirm there is no firewall blocking github.com, and try again. Do not proceed until the download succeeds.
4

Entering Device Credentials and Display Settings

After the download completes, the installer will prompt for four pieces of information. Enter each carefully — these credentials are written to the device config file and must be correct for the player to connect to Impact Cloud+.

  • 1

    Terminal ID — When prompted with ? Terminal ID :, enter the Terminal ID exactly as it appears in the Impact Cloud+ portal. Press Enter.

    The Terminal ID is case-sensitive. Copy it directly from the Cloud+ portal where possible to avoid transcription errors.
  • 2

    Terminal Secret — When prompted with ? Terminal Secret :, enter the Terminal Secret. Press Enter.

  • 3

    Cloud+ Server URL — When prompted with ? Cloud+ server URL [https://access.impactledsigns.com/] :, press Enter to accept the default unless you have been given a different server address.

  • 4

    Display Width — When prompted with ? Display width [1920] :, enter the correct width in pixels or press Enter to accept the 1920 default.

  • 5

    Display Height — When prompted with ? Display height [1080] :, enter the correct height in pixels or press Enter to accept the 1080 default.

  • 6

    Fullscreen Mode — When prompted with ? Fullscreen mode (true/false) [true] :, press Enter to accept the default true for a sign installation. Only enter false if this is a testing or preview setup.

After Entering Credentials The installer will display "Beginning installation…" and proceed automatically through four steps: downloading the release, installing files, writing the config, and registering startup tasks. No further input is required.
5

Verifying a Successful Installation

Once the installer completes, verify each of the following before closing the Command Prompt window.

  • 1

    Confirm the installer finished successfully. The final output should display:

    [OK] Installation complete!

    If you see any [ERROR] lines, do not proceed. See Section 6 — Troubleshooting.

  • 2

    Check the installed version. In the same Command Prompt window, run:

    type C:\ImpactLED\CloudPlayer\version.txt

    This should print the current version number (e.g. v1.0.5). If the file does not exist, the installer did not complete successfully.

  • 3

    Verify the startup tasks are registered. Press Win + R, type taskschd.msc, and press Enter. In the Task Scheduler Library, confirm both of the following tasks are present:

    • ImpactLED Cloud+ Desktop Player — triggers at logon, runs the player
    • ImpactLED Cloud+ Updater — triggers at startup, checks for updates 5 minutes after boot

    If either task is missing, run the manual registration commands in Section 6.

  • 4

    Confirm the player launched. A new window titled "ImpactLED Cloud+ Desktop Player" should have opened automatically. The screen will display the Impact Cloud+ logo while connecting. Within 30–60 seconds it should begin playing the assigned playlist.

  • 5

    Confirm Cloud+ connectivity. Press I on the keyboard while the player is focused to toggle the on-screen HUD. The HUD will show the connection status. Confirm it reads online. If it shows an error, verify the Terminal ID and Terminal Secret in the settings panel (F12).

  • 6

    Test autostart. Reboot the machine. The player should launch automatically after login without any manual steps. If it does not start, verify the Task Scheduler tasks from step 3.

Installation Complete If all six checks pass, the installation is confirmed. The device will auto-update whenever a new version is released — no further maintenance is required unless credentials change.
6

Troubleshooting Common Issues

Symptom / Error Cause & Resolution
The system cannot find the path specified The %TEMP% variable did not expand correctly. This happens when the command is run in PowerShell instead of Command Prompt. Close PowerShell and reopen an Admin Command Prompt (CMD), then run the command again. Also check that both %TEMP% references in the command have a % on each side.
[ERROR] Must be run as Administrator The Command Prompt was not opened with admin rights. Close it and follow Section 2 again, ensuring the title bar reads "Administrator: Command Prompt" before running the install command.
[ERROR] Download failed The machine cannot reach GitHub. Verify the internet connection is active. If on a managed network, ask the IT contact to confirm that github.com and raw.githubusercontent.com are not blocked by a firewall or content filter.
[ERROR] ImpactLED-Cloud-Player.exe not found after extraction The GitHub release package is missing the compiled executable. This means a new version tag was pushed but the GitHub Actions build has not finished yet, or it failed. Wait 5 minutes and run the installer again. If the error persists, check the Actions tab at github.com/Sacton86/Cloud-Desktop-Edition for build errors.
Player window opens but shows no content The player connected to Cloud+ but no playlist is assigned to this terminal. Log into Impact Cloud+ at access.impactledsigns.com, locate the terminal by its Terminal ID, and assign a playlist. The player polls every 30 seconds and will pick up the content automatically.
HUD shows "offline" or connection error after launch The Terminal ID or Terminal Secret entered during install is incorrect. Press F12 to open the settings panel, navigate to the Impact Cloud+ Sync section, and correct the credentials. Changes take effect on the next poll cycle (within 30 seconds).
Startup tasks missing from Task Scheduler The schtasks registration step failed silently during install, usually due to a group policy restriction. Run the following two commands in an Admin Command Prompt to register them manually: schtasks /create /tn "ImpactLED Cloud+ Desktop Player" /tr "cmd /c \"C:\ImpactLED\CloudPlayer\run_player.bat\"" /sc ONLOGON /ru "%USERNAME%" /f schtasks /create /tn "ImpactLED Cloud+ Updater" /tr "cmd /c \"C:\ImpactLED\CloudPlayer\updater.bat\"" /sc ONSTART /delay 0005:00 /ru SYSTEM /f
Updated playlist not appearing on the player The player checks for content changes every 30 seconds. Wait up to one minute after updating a playlist in Cloud+. If the content still does not update, the player may need to be restarted — the updater will re-detect the change on the next sync cycle after restart.

Useful On-Site Commands

The following commands may be needed during a site visit. All require an Administrator Command Prompt unless noted.

  • ↓

    Check the installed version (no admin required):

    type C:\ImpactLED\CloudPlayer\version.txt
  • ↓

    Force an immediate update check (checks GitHub and updates if a new version is available):

    C:\ImpactLED\CloudPlayer\updater.bat
  • ↓

    Start the player manually without rebooting:

    C:\ImpactLED\CloudPlayer\run_player.bat
  • ↓

    Open the settings panel — while the player window is focused, press:

    F12

Player Keyboard Shortcuts — all keys require the player window to be focused:

Key Function
IToggle on-screen info / HUD — shows connection status and current playlist
F12Open settings panel — edit Terminal ID, Terminal Secret, and display settings
F11Toggle fullscreen mode on/off
SpacePlay / pause the current playlist
PUpload a screenshot of the current frame to Cloud+
OLoad a local file for playback (testing use)

8

Uninstalling the Player

To completely remove the player, startup tasks, and all installed files from a machine, run the following command in an Administrator Command Prompt. This is a single line — copy it in full.

schtasks /end /tn "ImpactLED Cloud+ Desktop Player" >nul 2>&1 && schtasks /end /tn "ImpactLED Cloud+ Updater" >nul 2>&1 && schtasks /delete /tn "ImpactLED Cloud+ Desktop Player" /f && schtasks /delete /tn "ImpactLED Cloud+ Updater" /f && taskkill /f /im "ImpactLED-Cloud-Player.exe" >nul 2>&1 && rmdir /s /q "C:\ImpactLED"

This will:

  • Stop the player and updater if they are currently running
  • Remove both startup tasks from Task Scheduler
  • Force-close the player executable if open
  • Delete the entire C:\ImpactLED\ folder and all contents
This action is irreversible. Device credentials stored in player_config.json will be permanently deleted. Record the Terminal ID and Terminal Secret before uninstalling if they will be needed for reinstallation.
